
# Student Study Planner & Deadline Tracker

## About the Project

Student Study Planner & Deadline Tracker is a web-based application developed using Python and Flask. It helps students organize their academic tasks, manage deadlines, track progress, and improve their study productivity.

The application provides a simple dashboard where students can add, update, delete, and manage their study tasks.

## Features

- Add new study tasks.
- Edit and delete existing tasks.
- Set deadlines for assignments and activities.
- Assign High, Medium, and Low priorities.
- Mark tasks as completed or pending.
- Search tasks by name.
- Filter tasks by subject, priority, and status.
- View total, pending, and completed tasks.
- Track overall study progress.
- View overdue and upcoming deadlines.
- Visualize task progress using a doughnut chart.
- View productivity messages based on task completion.

## Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/student-study-planner.git
```

### 2. Open the Project Folder

```bash
cd student-study-planner
```

### 3. Create a Virtual Environment (Optional)

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the Application

```bash
python app.py
```

### 6. Open in Browser

Visit:

```text
http://127.0.0.1:5000/
```
